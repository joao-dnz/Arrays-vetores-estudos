# Exercício de Vetores (Arrays) em Java

Exercício prático desenvolvido durante meus estudos de Java, com foco na utilização de vetores (`arrays`), laços de repetição `for`, estruturas condicionais `if` e contadores.

**Funcionalidades:**
- Armazenar notas em um vetor.
- Calcular a soma das notas.
- Contar quantas notas são maiores ou iguais a 7.
- Exibir os resultados no console.

**Tecnologias:** Java

**Objetivo:** Praticar os fundamentos de programação e a manipulação de vetores em Java.
